COT Field Survey v16 — เสียง/วิดีโอ และรายงาน PDF/Excel

ติดตั้ง (รอบนี้ต้องอัปเดต Apps Script ด้วย)
1. ใช้ Apps-Script-v16.gs แทนโค้ดเดิมทั้งไฟล์ในโปรเจกต์ Apps Script เดิม ตรวจ SHEET_ID และ SALT ให้เป็นค่าของคุณ
2. Deploy > Manage deployments > Edit > New version > Deploy เพื่อใช้ URL เดิม
   ถ้า URL เปลี่ยน ต้องแก้ API_URL ใน index.html ให้ตรงกัน
3. ถ้าระบบขอสิทธิ์ Drive/Sheets ให้เจ้าของสคริปต์อนุญาต รัน authorizeDrive() เพื่อขอสิทธิ์ Drive ได้
4. แตก ZIP เว็บแล้วอัปโหลดไฟล์ทั้งหมดทับชุดเดิม รวม JS ใหม่และ sw.js
5. เปิดแอปขณะออนไลน์แล้วรีเฟรชเพื่อรับแคชใหม่
ไฟล์ .gs เป็นโค้ดฝั่ง Apps Script แยกจาก ZIP เว็บ ไม่ต้องอัปโหลดไป GitHub Pages

ข้อ 4 — เสียง/วิดีโอ
- หน้า สำรวจ มีส่วน เสียง / วิดีโอ แยกจากภาพถ่าย บันทึกจากไมโครโฟน/กล้อง หรือเลือกไฟล์จากเครื่อง
- เสียงไม่เกิน 120 วินาที / 8 MB วิดีโอไม่เกิน 60 วินาที / 20 MB รวมไม่เกิน 3 ไฟล์ต่อรายการ
- ตรวจ MediaRecorder.isTypeSupported แล้วเลือก MP4/M4A ก่อน หากไม่รองรับจึงเลือก WebM/OGG
- ไฟล์นำเข้าต้องเป็นชนิดที่เครื่องอ่านความยาวได้ รองรับ MP4, M4A, AAC, MP3, WAV, OGG, WebM, MOV ตามความสามารถเบราว์เซอร์
- ตรวจฟัง/ดูและลบก่อนบันทึกได้ ไฟล์จะเข้า IndexedDB พร้อมรายการเมื่อกด บันทึกข้อมูล
- ต้องหยุดบันทึกและรอตรวจไฟล์ก่อนบันทึกข้อมูล การปิดแอปก่อนกดบันทึกข้อมูลยังไม่ถือว่าเก็บลงคิวแล้ว
- ส่งเป็นส่วนย่อยประมาณ 256 KiB ใช้รหัสไฟล์และ SHA-256 เดิมเสมอ
- เน็ตหลุดหรือปิดแอประหว่างส่ง เปิดใหม่แล้วส่งต่อจากส่วนที่เซิร์ฟเวอร์รับแล้ว ต้องเปิดแอปไว้ขณะส่ง โดยเฉพาะ iPhone
- หน้าแก้ไขรายการในคิวเพิ่ม/ลบเสียงและวิดีโอได้ก่อนเริ่มส่ง ส่วนนี้บันทึกการเพิ่ม/ลบไฟล์ลงคิวทันทีตามข้อความในหน้า
- เพิ่มแท็บ Attachments ในไฟล์ชีตโครงการอัตโนมัติ เก็บไฟล์ใน Photos/รหัสรายการ/ ร่วมกับภาพ
- ส่วนไฟล์ชั่วคราวอยู่ในโฟลเดอร์ _upload_รหัสไฟล์ และเข้า Trash ของ Drive หลังรวมและตรวจ SHA-256 สำเร็จ
- ไม่เปิดไฟล์ใน Drive เป็นสาธารณะ โหลดผ่าน API เพื่อเล่น/ดาวน์โหลดในหน้ารายละเอียด และเก็บแคชไว้ใช้ครั้งต่อไป
- ถ้าเครื่องเล่น codec ไม่ได้ มีลิงก์ดาวน์โหลดเพื่อเปิดด้วยแอปอื่น
- รอบนี้แนบไฟล์ผ่านการสร้างรายการใหม่และแก้ไฟล์ในคิวก่อนส่ง ยังไม่มีการเพิ่มไฟล์ให้รายการเก่าที่ส่งแล้วจากหน้ารายละเอียด

ข้อ 7 — รายงาน
- แท็บ แผนที่ มีปุ่ม รายงาน PDF / Excel เลือกทุกรายการที่โหลดไว้หรือเฉพาะตามตัวกรอง
- ไม่รวมรายการที่อยู่เฉพาะในเครื่องและยังไม่สร้างบนเซิร์ฟเวอร์ รายการที่สร้างบนเซิร์ฟเวอร์แล้วแสดงตามสถานะที่แอปโหลดไว้
- มีตารางรายการ ภาพย่อไม่เกิน 1 ภาพต่อรายการ และแผนผังพิกัดรวม ไม่มีแผนที่ฐาน จึงไม่ต้องโหลดบริการแผนที่เพิ่ม
- PDF มีหน้าสรุปและรายละเอียดพร้อมภาพ ภาษาไทยสร้างเป็นภาพหน้าเอกสารเพื่อคงรูปข้ามอุปกรณ์ จึงค้นหา/คัดลอกตัวอักษรจาก PDF ไม่ได้
- Excel เป็น XLSX จริง มีชีต สรุป / รายการสำรวจ / ไฟล์แนบ พร้อมภาพย่อและภาพรวมพิกัด
- GeoJSON ที่ยาวเกินขนาดเซลล์จะแสดงข้อความให้ใช้ Export GeoJSON จากแอปเพื่อรับรูปทรงเต็ม แผนผังยังใช้รูปทรงเต็ม
- Drive URL ใน Excel เปิดได้ตามสิทธิ์ Drive ของผู้เปิด ไฟล์ยังไม่เป็นสาธารณะ
- ออฟไลน์ใช้รายการ ภาพย่อ และข้อมูลไฟล์แนบที่เคยเก็บไว้ ถ้าไม่เคยโหลดจะแสดงว่าไม่ได้โหลดข้อมูลส่วนนั้น
- รายงานจำนวนมากใช้เวลา/หน่วยความจำมาก ยกเลิกระหว่างเตรียมข้อมูลหรือใช้ตัวกรองลดจำนวนได้
- iPhone ที่เปิดไฟล์เป็นพรีวิว ใช้เมนูแชร์เพื่อบันทึกลงแอปไฟล์ได้

Apps Script ที่เพิ่ม/เปลี่ยน
- action ใหม่: attachmentBegin, attachmentChunk, attachmentFinish, listAttachments, getAttachmentChunk, reportData
- createSurvey ตรวจและลงทะเบียนไฟล์แนบ ใช้ ClientKey และ AttachmentID เดิมกันซ้ำ
- refresh รวมสถานะไฟล์แนบกับภาพถ่าย โดยไม่รวมไฟล์แนบเป็นจำนวนภาพ
- เพิ่มแท็บ Attachments อัตโนมัติ ไม่ต้องสร้างหัวคอลัมน์เอง
- ไม่มีถังขยะหรือกู้คืนรายการ (ข้อ 5 ไม่อยู่ในรุ่นนี้)

ผลตรวจสอบ
- Playwright / Edge headless: บันทึกเสียง/วิดีโอด้วย MediaRecorder จริงและกล้อง/ไมโครโฟนจำลอง ตรวจความยาวและจำนวนไฟล์
- เก็บ Blob ออฟไลน์ ส่งแบบคำตอบหายหลังเซิร์ฟเวอร์รับแล้ว รีโหลดและส่งต่อโดยไม่ส่งส่วนเดิมซ้ำ
- ตรวจ SHA-256 การส่งซ้ำ/รวมซ้ำ ขอบเขตโครงการ และดาวน์โหลดส่วนตัวด้วย Apps Script/Drive จำลอง
- เล่นจากแคช/โหลดผ่าน API เพิ่ม/ลบไฟล์ในคิว ดาวน์โหลด PDF/XLSX และรายงานออฟไลน์
- เปิด XLSX ตรวจศูนย์นำหน้า รูปภาพ และ XML ทุกส่วน Render PDF/Excel ตรวจภาษาไทย ตาราง และภาพ
- ทดสอบข้อความยาว 2,000 อักขระต่อหลายหน้า PDF และ geometry 5,000 จุด
- ตรวจซ้ำวาด/แก้ node, GPS จำลอง, คิว geometry เดิมผ่าน ไม่พบ JavaScript error ที่ไม่คาดหมาย
- การจำลองเน็ตหลุดมี network error ตามที่ตั้งใจ

ข้อจำกัดการทดสอบ
