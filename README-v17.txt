COT Field Survey v17

แก้ไขตามภาพ
- เอาปุ่ม ไปยังตำแหน่งของฉัน ใต้กรอบแผนที่ออก ปุ่มตำแหน่งลอยในกรอบแผนที่ยังทำงานเหมือนเดิม
- ใส่ปุ่ม Export KML / KMZ แทนตำแหน่งเดิม
- หน้ารายงาน PDF/Excel เปลี่ยนขอบเขตข้อมูลจาก dropdown เป็นปุ่ม ทั้งโครงการ / ตามตัวกรองแผนที่
- เปิดหน้ารายงานแล้วโฟกัสหัวหน้าต่าง ไม่มีช่อง select ให้ iPhone เปิดเมนู native เอง

KML / KMZ
- กด Export KML / KMZ แล้วเลือกรูปแบบที่ต้องการ
- ค่าเริ่มต้นคือ ตามตัวกรองแผนที่ เลือก ทั้งโครงการ เพื่อส่งออกทุกรายการที่แอปโหลดไว้ได้
- ใช้ข้อมูลในเครื่อง ไม่ต้องเรียกเซิร์ฟเวอร์เพิ่ม รองรับออฟไลน์เมื่อเปิดแอปและโหลดไฟล์เว็บไว้แล้ว
- รักษารูปทรง Point / LineString / Polygon รวมวงรอบด้านในของ Polygon หากข้อมูลมีอยู่
- พิกัดเป็น longitude,latitude,0 ตาม KML 2.2 แนบกับพื้นดิน ไม่ใช่ค่าความสูงสำรวจ
- ส่งรหัส ประเภท ผู้สำรวจ สถานะ วันที่ รายละเอียด จำนวนภาพ และฟิลด์เพิ่มเติมใน ExtendedData
- รักษาเลขศูนย์นำหน้าและภาษาไทย Escape อักขระ XML ที่อาจอยู่ในข้อมูล
- KMZ เป็น ZIP ที่มี doc.kml อยู่ด้านบนสุด ใช้เปิดใน Google Earth หรือโปรแกรม GIS ที่รองรับ
- ไม่แพ็กรูปถ่าย เสียง วิดีโอ หรือแผนที่ฐานเข้า KML/KMZ
- ถ้ามีพิกัดไม่ถูกต้อง จะยังไม่ดาวน์โหลดและระบุรหัสรายการให้แก้ไขหรือกรองออก ไม่ส่งไฟล์ที่ขาดรายการโดยเงียบ ๆ
- รายการใหม่ที่ยังอยู่เฉพาะในคิวและไม่ได้สร้างบนเซิร์ฟเวอร์ยังไม่อยู่ในชุดส่งออก

ติดตั้ง
1. อัปโหลดไฟล์เว็บทั้งหมดใน ZIP ทับชุดเดิม รวม geo-export.js, survey-reports.js, index.html และ sw.js
2. เปิดแอปขณะออนไลน์แล้วรีเฟรชเพื่อรับแคช v17
3. ถ้าใช้ Apps Script v16 แล้ว ไม่ต้องแก้หรือ Deploy ใหม่สำหรับ v17
รายละเอียดเสียง/วิดีโอและการติดตั้ง Apps Script ครั้งแรกดูใน README-v16.txt ซึ่งเก็บไว้ใน ZIP นี้ด้วย

ผลตรวจสอบ
- Playwright / Edge headless ขนาด 390x844 รวมการแตะบนมือถือจำลอง
- ตรวจปุ่มตำแหน่งลอยหลังเอาปุ่มซ้ำออก ไม่มี JavaScript อ้างถึงปุ่มที่ลบแล้ว
- ตรวจหน้ารายงานไม่มี select, โฟกัสหัวเรื่อง และส่ง PDF เฉพาะรายการที่กรองได้
- ตรวจ KML จุด/เส้น/พื้นที่และวงรอบด้านใน ข้อความไทย อักขระพิเศษ ขอบเขตข้อมูล และการปฏิเสธพิกัดไม่ถูกต้อง
- ตรวจ XML namespace พิกัดเรียง longitude/latitude การปิดวงรอบ และทิศทางวงรอบ Polygon
- ตรวจ KMZ ขณะออฟไลน์ โดย doc.kml ตรงกับ KML ที่ส่งออกทุกไบต์
- ตรวจกรอบรายงานขนาด 320x568, 844x390 และ 1280x900
- ไม่พบ JavaScript page errors หรือ console errors
- ใช้ API/GPS จำลอง ยังไม่ได้เปิดไฟล์ใน Google Earth จริงหรือทดสอบ Safari บน iPhone เครื่องจริง
