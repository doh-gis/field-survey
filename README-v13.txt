COT Field Survey v13 — หน้าต่างวาดและแก้ไขรูปทรง

ติดตั้ง
1. แตก ZIP แล้วอัปโหลดไฟล์เว็บทั้งหมดทับชุดเดิมบน GitHub Pages รวม geometry-editor.js และ sw.js
2. เปิดแอปขณะออนไลน์แล้วรีเฟรชหนึ่งครั้ง เพื่อรับไฟล์และแคชเวอร์ชันใหม่
3. Apps Script ใช้โค้ดเดิมจาก v12 ได้ ไม่มีการเปลี่ยน API หรือโครงสร้างชีตในรอบนี้

ใช้งาน
- เลือก “เส้น” หรือ “พื้นที่ปิด” ในหน้า สำรวจ แล้วหน้าต่างแผนที่จะเปิดทันที
- เพิ่มจุด: แตะแผนที่ในโหมด เพิ่มจุด
- ย้ายจุด: ลากวงกลมหมายเลขได้ด้วยเมาส์หรือสัมผัส
- แทรกจุด: แตะหรือลากเครื่องหมาย + ระหว่างจุด รวมด้านปิดของ Polygon
- ลบจุด: แตะวงกลมหมายเลข แล้วกด ลบจุดที่เลือก
- ย้อนกลับ: คืนค่าก่อนเพิ่ม ย้าย แทรก ลบ หรือล้างจุด
- ใช้รูปทรงนี้: นำรูปทรงกลับเข้าแบบฟอร์ม แล้วกดบันทึกข้อมูลตามปกติ
- ยกเลิก: ทิ้งเฉพาะการแก้ไขในหน้าต่างนี้ โดยคงรูปทรงก่อนเปิดไว้
- แก้รายการเดิม: เปิดรายละเอียด > แก้ไข > เปิดหน้าต่างแก้ไขรูปทรง > ใช้รูปทรงนี้ > บันทึกการแก้ไข

การตรวจสอบ
ทดสอบด้วย Playwright บน Edge headless ที่ 390x844 และ 1280x900:
- เปิดหน้าต่างโดยไม่เปลี่ยนแท็บหรือสร้างแผนที่หลัก
- เพิ่ม ลากด้วยเมาส์และสัมผัส แทรก ลบ และย้อนกลับจุด
- ยกเลิกแล้วไม่เปลี่ยนรูปทรงเดิม
- ปิดวง Polygon และบันทึกกลับแบบฟอร์ม
- บันทึกออฟไลน์ใน IndexedDB และส่ง geometry เดิมหลังกลับออนไลน์
- แก้รายการเดิมโดยไม่เปลี่ยนข้อมูลจริงก่อนกดบันทึก
- ไม่พบ JavaScript page errors หรือ console errors
ใช้ API จำลองในการทดสอบ ไม่ได้เขียนข้อมูลลง Apps Script/ชีตจริง
GPS จริง กล้อง และอุปกรณ์ iPhone จริงยังไม่ได้ทดสอบในรอบนี้
