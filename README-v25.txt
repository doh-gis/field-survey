COT Field Survey v25 — รายงานแบบย่อและแผนที่ขยาย

วิธีอัปเดต
แต่ละ ZIP เป็นชุดเว็บครบและสะสมจากเวอร์ชันก่อนหน้า ไม่ใช่แพตช์เฉพาะไฟล์
อัปโหลดไฟล์เว็บทั้งหมดของเวอร์ชันที่ต้องการทับชุดเดิม แล้วเปิดออนไลน์และรีเฟรช
หากยังเห็นชุดเก่า ให้ปิดแล้วเปิดแอปอีกครั้ง ดูหมายเลขรุ่นได้ในแท็บผู้ใช้งาน
ใช้ Apps Script v16 เดิม ไม่ต้องแก้หรือ deploy backend เพิ่ม
ไม่ต้องติดตั้งทุกเวอร์ชัน หากต้องการฟังก์ชันทั้งหมดเลือก v25 ได้เลย
อย่าล้างข้อมูลเว็บไซต์ถ้ายังมีฉบับร่างหรือรายการรอส่ง

เพิ่มจาก v24 (ข้อ 7 ตามแผนล่าสุด)
เลือกแบบย่อ/พร้อมรายละเอียด เปิดปิดภาพย่อ เลือกแผนที่รวม/แยกพื้นที่/รายรายการ แสดงจำนวนรายการและภาพก่อนสร้าง เตือนรายงานขนาดใหญ่ PDF เพิ่มหน้าแผนที่ขยาย Excel เพิ่มชีตแผนที่ขยาย

สิ่งที่รวมในรุ่นนี้
- v20: สถานะบันทึกและส่งข้อมูล
- v21: หน้าตาและพื้นที่แผนที่
- v22: บันทึกและสำรวจจุดถัดไป
- v23: ตัวกรองและค้นหา
- v24: ตรวจพิกัดและรูปทรง
- v25: รายงานแบบย่อและแผนที่ขยาย
- ฟังก์ชันเดิมและฉบับร่างอัตโนมัติจาก v19

วิธีตรวจรุ่นนี้
เลือกอย่างน้อยสองพื้นที่ห่างกัน ลองแบบย่อ PDF และพร้อมรายละเอียด+แยกพื้นที่ทั้ง PDF/Excel ตรวจภาพ ตำแหน่ง รหัสรายการ ชีตแผนที่ขยาย จากนั้นลองตามตัวกรองและปิดภาพย่อ

รายละเอียดที่ควรทราบ
- ฉบับร่าง ประวัติส่ง และขอบเขตพื้นที่เป็นข้อมูลในเครื่อง/เบราว์เซอร์นี้
- การจำค่าจุดถัดไปใช้เฉพาะหน้าสำรวจทีละรายการ ไม่จำพิกัดหรือไฟล์แนบ
- ขอบเขตพื้นที่เป็นกรอบสี่เหลี่ยมตั้งเอง ไม่ใช่เขตปกครองอัตโนมัติ และไม่ซิงก์ให้ทีมอื่น
- การเตือนนอกขอบเขตพร้อมเหตุผลใช้กับการบันทึกหน้าสำรวจทีละรายการ
  ไม่นำขอบเขตไปเปลี่ยนข้อมูลเก่า และยังไม่ตรวจนอกพื้นที่เป็นชุดในหน้านำเข้าหลายรูป
- รูปทรงตรวจเส้นตัดกันเมื่อกดใช้รูปทรง/บันทึก ไม่แทนการตรวจ GIS เต็มรูปแบบ
- วันที่ตัวกรองใช้วันตามเวลาท้องถิ่นของอุปกรณ์
- รายงานแยกพื้นที่ใช้พิกัดตัวแทนจัดกลุ่มตามระยะที่เลือก (ค่าเริ่มต้น 20 กม.)
  จุดที่เชื่อมต่อกันจะอยู่กลุ่มเดียวกัน ไม่ใช่การแบ่งตามชื่อจังหวัดหรือขอบเขตที่ตั้งไว้
- รายงานแบบย่อ PDF ไม่มีหน้ารายละเอียด ส่วน Excel ยังคงตารางข้อมูลทั้งหมดแต่ไม่ฝังภาพถ่าย
- แผนที่ขยายได้สูงสุด 50 ภาพต่อไฟล์ หากเกินจะแจ้งให้กรองหรือใช้แผนที่รวม ไม่ตัดรายการทิ้ง
- ขนาดไฟล์จริงขึ้นกับภาพและรายละเอียด หน้ารายงานแจ้งจำนวนภาพ/แผนที่ก่อนเริ่ม
- รายงานใช้ข้อมูลที่โหลดไว้ ไม่รวมคิวที่ยังไม่ขึ้นเซิร์ฟเวอร์
- แผนที่ต้องโหลดออนไลน์ก่อนหรือมีข้อมูลในแคช หากโหลดไม่ครบจะไม่สร้างรายงานพื้นว่าง
- PDF เป็นภาพหน้ากระดาษเพื่อรองรับอักษรไทย ค้นหา/คัดลอกข้อความใน PDF ไม่ได้ตามระบบเดิม
- ไม่เพิ่มระบบสิทธิ์ผู้ใช้ ประวัติการแก้ไข หรือถังขยะตามที่ตัดออกจากแผน

การทดสอบ
ทดสอบด้วย Edge จำลองมือถือ/เดสก์ท็อป และ API จำลอง ไม่แก้ข้อมูลจริง
ครอบคลุมการส่งขาดสัญญาณแล้วลองใหม่ คิว/ฉบับร่างออฟไลน์ การจำค่าจุดถัดไป
ตัวกรองและไฟล์ส่งออก การวาด/ลากจุด/ย้อนกลับ/ยกเลิก ตรวจรูปทรงและเหตุผลนอกพื้นที่
สร้าง PDF/XLSX แบบย่อ/พร้อมภาพ/แผนที่ขยาย ใช้แคชออฟไลน์ และเรนเดอร์ตรวจหน้ากระดาษ/ชีต
แผนที่รวมใช้ภาพแผนที่จริงที่เก็บไว้ในการทดสอบ ส่วนภาพขยายบางชุดใช้กระเบื้องภาพทดสอบซ้ำ
เพื่อทดสอบการวางภาพและฝังไฟล์โดยไม่ดึงข้อมูลผู้ให้บริการเพิ่ม
ยังต้องตรวจประสบการณ์ใช้งานบน iPhone จริง โดยเฉพาะกล้อง ไมโครโฟน ดาวน์โหลด และความจำเครื่อง
