COT Field Survey v18 — แผนที่ฐานในรายงาน PDF / Excel

สิ่งที่แก้
- รายงานเดิมใช้แผนผังพิกัดไม่มีแผนที่ฐาน รุ่นนี้เปลี่ยนเป็นภาพแผนที่จริงพร้อมตำแหน่งและรูปทรงสำรวจ
- ใช้ชั้นแผนที่ที่เลือกในแท็บแผนที่ เช่น ถนน OSM, ดาวเทียม Esri, ดาวเทียมพร้อมชื่อ/ถนน
- ซูมรวมทุกตำแหน่งในชุดข้อมูลที่เลือกรายงาน ไม่ได้จำกัดแค่ส่วนที่กำลังซูมดูอยู่
- รวมป้ายรหัสที่อยู่ใกล้กันเพื่อลดการซ้อนข้อความ พร้อมขอบขาวให้เห็นบนภาพดาวเทียม
- แสดงแหล่งที่มาของแผนที่บนภาพและในชีต Excel
- สร้างภาพให้ครบก่อนดาวน์โหลด ไม่ส่งออกไฟล์ที่แผนที่เป็นพื้นว่างเพราะเน็ตหลุด
- ตัวอย่างภาพแผนที่ปรากฏในหน้ารายงานหลังสร้างภาพสำเร็จ

ใช้งาน
1. ในแท็บ แผนที่ เลือกชั้นแผนที่ที่ต้องการ
2. กด รายงาน PDF / Excel แล้วเลือกขอบเขตข้อมูลตามเดิม
3. กดดาวน์โหลดและรอโหลดแผนที่ให้ครบครั้งแรก
4. หากออฟไลน์ จะใช้ภาพแผนที่ที่เคยเก็บไว้สำหรับชั้นและขอบเขตเดียวกันได้
5. ถ้าไม่มีภาพหรือกระเบื้องแผนที่ในเครื่องจะแจ้งว่าโหลดแผนที่ฐานไม่ครบ ให้เชื่อมต่ออินเทอร์เน็ตแล้วลองใหม่ หรือเปลี่ยนชั้นแผนที่

แคชและการโหลด
- โหลดเฉพาะกระเบื้องที่ใช้สร้างภาพรายงานหนึ่งมุมมอง ไม่ดาวน์โหลดพื้นที่หลายระดับซูมล่วงหน้า
- ใช้แคชกระเบื้องของแอปและ HTTP ตามเดิม และเก็บภาพแผนที่รายงานล่าสุดไว้ไม่เกิน 8 มุมมอง
- ขณะออนไลน์ ภาพแคชมีอายุ 7 วัน ขณะออฟไลน์ยังใช้ภาพเดิมที่มีได้
- รูปทรง/สถานะ/รหัสวาดใหม่จากชุดข้อมูลของรายงานทุกครั้ง แคชเก็บเฉพาะภาพแผนที่ฐาน
- หากแผนที่ต่างชั้นหรือขอบเขตเปลี่ยน อาจต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลดภาพใหม่

ติดตั้ง
- อัปโหลดไฟล์ทั้งหมดใน ZIP ทับชุดเดิม โดยเฉพาะ index.html, report-map.js, survey-reports.js และ sw.js
- เปิดขณะออนไลน์แล้วรีเฟรชเพื่อรับแคชใหม่
- Apps Script ใช้ v16 เดิมได้ ไม่ต้องแก้หรือ Deploy ใหม่สำหรับ v18
- รายละเอียดเสียง/วิดีโอและ KML/KMZ ดู README-v16.txt และ README-v17.txt
- ข้อความเรื่องรายงานไม่มีแผนที่ฐานใน README รุ่นเก่าถูกแทนด้วยพฤติกรรม v18 นี้

ผลตรวจสอบ
- Playwright / Edge headless ขนาดมือถือ 390x844
- โหลดแผนที่จริงจาก OSM และ Esri World Imagery พร้อมชั้นชื่อและถนน
- สร้าง PDF/XLSX แล้วตรวจภาพแผนที่ที่ฝังไว้ทั้งสองรูปแบบ
- Render PDF หน้าแรกทั้งถนนและดาวเทียม และ Render ชีตสรุป Excel ตรวจด้วยภาพ
- ทดสอบตำแหน่งที่ห่างกันระหว่างกรุงเทพฯ/ภาคใต้ เพื่อให้เห็นภาพรวมทุกตำแหน่ง
- ทดสอบออฟไลน์หลังเคยสร้างภาพแผนที่แล้ว ออก PDF/XLSX ได้
- ทดสอบออฟไลน์โดยลบภาพแคช ไม่มีการดาวน์โหลด PDF เปล่าและมีข้อความแจ้งให้โหลดแผนที่ใหม่
- ไม่พบ JavaScript error ที่ไม่คาดหมาย มี network error เฉพาะกรณีจำลองออฟไลน์ที่ตั้งใจ
- ใช้ API รายการสำรวจจำลอง แต่ใช้ภาพแผนที่จริง ยังไม่ได้ทดสอบ Safari บน iPhone เครื่องจริง
