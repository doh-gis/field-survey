COT Field Survey v14

สิ่งที่แก้ไข
- เลือกรูปทรงด้วยปุ่มไอคอน จุด / เส้น / พื้นที่ปิด ค่าเริ่มต้นคือจุด
- เลือกเส้นหรือพื้นที่แล้วเปิดหน้าต่างวาดทันที และใช้ปุ่มเปลี่ยนรูปทรงภายในหน้าต่างเช่นกัน
- แทนที่ dropdown รูปทรงทั้งสองแห่ง เพื่อไม่ให้เมนู native ของ iPhone ค้างเมื่อเปิดหรือปิดหน้าต่าง
- ปรับขนาดและตำแหน่งหน้าต่างตาม Visual Viewport พร้อมพื้นที่ขอบจอและ safe area
- เพิ่มปุ่ม ตำแหน่งของฉัน เพื่อแพนไปยัง GPS ปัจจุบัน พร้อมจุดตำแหน่งและวงความแม่นยำ โดยไม่เปลี่ยนรูปทรงที่วาด
- แจ้งเหตุเมื่อใช้ GPS ไม่ได้ และไม่นำผล GPS ที่มาถึงหลังปิดหน้าต่างไปเปลี่ยนหน้าต่างรอบใหม่

ติดตั้ง
อัปโหลดไฟล์เว็บใน ZIP ทับของเดิมทั้งหมด รวม index.html, geometry-editor.js และ sw.js
เปิดแอปขณะออนไลน์แล้วรีเฟรชเพื่อรับแคชใหม่
Apps Script ใช้ตัวเดิมจาก v12 ได้ ไม่ต้องเพิ่มคอลัมน์หรือ Deploy ใหม่สำหรับ v14

การตรวจสอบ
ทดสอบด้วย Playwright บน Edge headless รวมการแตะและลากจุดบนมือถือจำลอง
ตรวจขนาดจอ 390x844, 390x650, 320x568, 844x390 และเดสก์ท็อป 1280x900
ตรวจปุ่มเลือกค่าเริ่มต้น การเปิด/ปิดหน้าต่าง ยกเลิก เพิ่ม/แทรก/ย้าย/ลบ/ย้อนกลับ node
ตรวจการแพนด้วย GPS จำลอง การปฏิเสธสิทธิ์ และผล GPS ที่มาถึงหลังปิดหน้าต่าง
ตรวจคิวออฟไลน์และ geometry ที่ส่งกลับ API จำลอง รวมการแก้รายการเดิม
ไม่พบ JavaScript page errors หรือ console errors
ยังไม่ได้ทดสอบ Safari บน iPhone เครื่องจริง หรือ GPS และ Apps Script จริงในรอบนี้
